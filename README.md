# KSeF pod kontrolą — landing page

Statyczna, responsywna strona sprzedażowa polskiego poradnika PDF. Można ją opublikować na Netlify lub dowolnym hostingu statycznym.

## Podgląd lokalny

Otwórz index.html w przeglądarce albo uruchom lokalny serwer statyczny w katalogu projektu.

## Przed publikacją sprzedaży

1. Cena wynosi 39,99 zł. Link zakupu w Naffy jest skonfigurowany w script.js i w głównych przyciskach strony.
2. Sposób i termin dostawy PDF przedstaw w koszyku Naffy przed złożeniem zamówienia.
3. Uzupełnij wszystkie pola [DO UZUPEŁNIENIA] w regulamin.html, polityka-prywatnosci.html i odstapienie.html. W szczególności podaj dane sprzedawcy i skuteczny kontakt w informacjach przed zakupem; placeholdery nie są wystarczającą informacją dla klienta.
4. Skonfiguruj w koszyku osobną, dobrowolną, domyślnie niezaznaczoną zgodę na rozpoczęcie dostarczania treści cyfrowej przed upływem terminu odstąpienia oraz potwierdzenie tej zgody na trwałym nośniku, jeśli chcesz dostarczać PDF od razu.
5. Zaktualizuj politykę prywatności po wyborze hostingu, koszyka, operatora płatności i narzędzi. Obecna strona pobiera czcionki z Google Fonts. Zweryfikuj faktyczne logi hostingu, cookies, odbiorców danych, okresy przechowywania i formularze.
6. Pełny plik PDF prześlij wyłącznie do wybranej platformy sprzedażowej. Nie umieszczaj go w tym repozytorium ani w publicznym katalogu hostingu.

Dodane dokumenty są czytelnymi szablonami informacyjnymi, ale nie mogą być uznane za kompletne ani gotowe do sprzedaży bez wpisania rzeczywistych danych i dopasowania do koszyka oraz przepływu danych.

Obraz w katalogu public/images jest ilustracją strony, nie częścią płatnego produktu. Wizualizacje checklist i schematu w sekcji podglądu są makietami HTML opartymi na tematach poradnika, a nie zrzutami stron PDF.
